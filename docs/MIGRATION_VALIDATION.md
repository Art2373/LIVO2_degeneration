# 独立构建与迁移验证：2026-10-12

本文件仅记录当前源码包的新构建结果，实际版本以根目录 RELEASE.json、交付 SHA256 文件清单为准。默认采用 measurement_commit_v1、burst 和原撤回清理/重建参考流程。

## 构建与测试

从空的独立工作空间构建，包括重新生成消息和从源码编译五个核心库、Sophus、vikit、cv_bridge及压缩图像插件，没有使用其他项目旧对象或旧核心库。编译环境为 Jetson Orin NX / Ubuntu 20.04 / ROS Noetic / OpenCV 4.5.4。运行中的核心库来自本工程；Python cv2、cv_bridge 和加载 OpenCV 版本一致，实际 RGB 转换及 gray/resize/Sobel 检查通过。

6项 C++ 测试、5项参数/注入工具测试和分析边界检查全部通过。覆盖调度/队列、反馈信息与有限提交、零信息、合法零增量、非位姿信息、回滚、非有限、事件身份和模型代次。测试区分 Tracker 逻辑与真实 VIO 受控求解；未做全路径 ASan 验证。墙钟单元测试不算真实播放器暂停验收。

首次构建包装器发现系统 ROS setup 对未设变量与严格 shell 选项不兼容，随后发现视觉库对地图库的 CMake 链接声明遗漏。两项仅修复独立构建入口/依赖，求解源码不变；修复前失败证据保留在项目外。

## 固定四组完整回归

Wheel-float01，半速，从原起点至自然 EOF，+15秒允许给定参数接入；R/B/S的故障均在+43–51传感器秒，EOF另观察3墙钟秒。H健康；R停送RGB；B只替换为黑图；S停止并以相同参数、新服务会话重启。每组一次。

- R：故障前持续条件 sustained，恢复 sustained；从first_restored_original_pixel到持续信息提交为 0.684097 /clock秒、1.372415墙钟秒。
- B：故障前持续条件 sustained，恢复 sustained；从first_restored_original_pixel到持续信息提交为 1.673877 /clock秒、3.339885墙钟秒。
- S：故障前持续条件 sustained，恢复 sustained；从new_session_started到持续信息提交为 1.029928 /clock秒、2.059531墙钟秒。

黑图实际送达 239 帧，36 次被调用，其中 36 次无位姿测量信息；黑图A/B/C为4/0/0，零信息成功计票、刷新成功和清失败的违规次数为 0。

所有故障恢复均按实际新图/新会话及连续至少3次、跨度至少0.2修正图像秒判断；FUSING不是替代证据。普通运行没有触发的重复、过期或跨代次反馈拒绝分支，仍仅由针对性测试支持，不能写成现场主动注入已验证。

四组EOF时均有2张待处理图像，随后撤回清理而非被处理。只能对最后一张图像确认其修正时间比最后IMU晚49.982405 ms，不能给前一张自动套用同一原因。R/B的gate比压缩源各少1张，归属未知；原始压缩RGB、LiDAR、IMU接收计数均与全bag一致，不代表每层都无缺失。实际回放没有出现“零位姿增量但有信息提交”的案例，该合法情形由针对性求解测试覆盖。自然撤回、恢复等待和调用差异均保存，不把此次调用数量变化解释为方法改进。实际结构化表、原始日志和加载库记录保存在项目外迁移证据中，可由交付者提供，避免源码包夹带大型日志。

## 复现与边界

构建与四组复现入口见 README 和 docs/RUNNING.md。源码包提供独立输入契约生成和哈希预检，使用者自行提供bag。实际源码/二进制哈希见 RELEASE.json；校验整个交付树使用外附文件清单。

Retail兼容性不利结果、未采用候选的负结果见 VALIDATION_AND_LIMITS.md。当前发布未验证真实暂停、1倍速、严格定位精度或普遍跨配置能力。PROBING改变真实状态，撤回不抹除历史视觉影响，半速不能证明实时性。
